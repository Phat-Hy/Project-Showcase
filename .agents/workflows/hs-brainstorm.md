# hs-brainstorm

Use the `brainstorm` skill to clarify requirements, analyze choices, and compare tradeoffs for Gara Startup platform features.

## Trajectory
1. Analyze the user request or design target.
2. Outline the potential solutions, technical strategies, and architectural paths.
3. Compare the tradeoffs (e.g. security, complexity, development speed).
4. Raise clarifying questions for the user to select the best approach.
