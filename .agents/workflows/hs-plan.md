# hs-plan

Use the `plan` skill to construct concrete step-by-step implementation changes and verification criteria for Gara Startup platform features.

## Trajectory
1. Read the product requirements (BRD, PRD) in `.harness/specs/` to understand the goal.
2. Examine the codebase for any relevant controllers, routers, migrations, or public web pages.
3. Write a comprehensive design plan in `real_product_implementation_plan.md` inside the artifacts directory.
4. Get user approval on the plan before implementing any code modifications.
